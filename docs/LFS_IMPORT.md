# ChatGPTからのGit LFS画像取込

専用ワークフローは、ChatGPTから明示的に依頼された画像だけをGit LFSへ登録する。

- `codex/lfs-import-*` ブランチ以外では起動しない。
- `.lfs-import/*.json` が追加された場合だけ起動する。
- 取込要求は1コミットにつき1ファイルだけ受け付ける。
- 保存先が `.gitattributes` で `filter=lfs` の対象か検査する。
- SHA-256とファイルサイズを検証してから登録する。
- 取込要求のコミットを消してブランチを書き換える。
- 最終的なPR履歴にはLFSポインタだけを残す。

通常のコミット、PR、画像以外の更新では実行されない。
