# ChatGPTからのGit LFS一括取込

明示的に依頼された画像・動画・配布ファイルを、1回のActionでまとめてGit LFSへ登録する。

- `codex/lfs-import-*` ブランチの `.lfs-import/*.json` へのpushで起動する。
- 取込要求コミットにはJSONだけを置く。大きい要求は複数JSONに分割し、同じコミットで追加する。すべてのJSONの `base_sha` は同じ親コミットを指定する。
- `files` 配列に複数ファイルを指定する。従来の単一ファイル形式も利用できる。
- 全件のパス、重複、LFS属性、SHA-256、サイズを検証してから作業ツリーを更新する。
- 通常のGitにはLFSポインタのみを保存し、実データはGit LFSへ送信する。
- 全件を1コミットにまとめ、取込要求コミットをブランチ履歴から除く。
- 既に同じポインタがある場合もLFS実データを送信する。その場合は空コミットを作らない。
- mainへの反映・PR作成は行わない。

```json
{
  "base_sha": "親コミットの40桁SHA",
  "files": [
    {
      "path": "docs/music/example/cover.png",
      "sha256": "実データのSHA-256",
      "size": 12345,
      "content_base64": "実データのBase64"
    }
  ]
}
```

Base64は元データより約33%大きくなる。要求JSONはGitHubのファイルサイズ制限内に収める。
取込要求には実データのBase64が一時的に含まれる。履歴の書き換えはGitHubのキャッシュや取得済みコピーの消去を保証しない。
